# World Clock & Stopwatch

A lightweight, precision browser-based digital clock and stopwatch application written in vanilla JavaScript.

## Features

- **Live Digital Display:** Real-time 12/24-hour time formatting with second and millisecond tickers.
- **Stopwatch:** Millisecond-accurate start, pause, and reset tracking using `requestAnimationFrame` and `performance.now()`.
- **Zero Dependencies:** Pure DOM manipulation without external libraries or frameworks.

## Tech Stack

- Vanilla JavaScript
- HTML5
- CSS3 Custom Properties

## Running Locally

Clone the repository and open `index.html` in your web browser.
